## 1️⃣ 飞书邮件授权（2 分钟，最近一次链接见对话）

- 点对话里最新的 `accounts.feishu.cn/oauth/v1/device/verify?...` 链接（10 分钟有效，过期回我「重新生成」）
- 或用飞书 App 扫 `mail_auth_qr.png`
- **完成后回「已授权」** → 我立即创建给 janet@devpost.com 的草稿（Ring sandbox 三问）给你确认发送
- 备用方案：若不想走 Lark 授权，任何邮箱可直接发，正文在 `docs/email-to-janet.md`

## 2️⃣ Devpost 报名（10 分钟）

- 打开 https://amazonappdev2026.devpost.com → Register / Login → 点 **Register for hackathon**
- 勾选：主赛道 **Ring** ＋ 迷你挑战 **AWS Builder**
- **带回**：报名成功状态即可（提交表单 10/22 前我来填内容，材料在 `docs/devpost-writeup.md`）

## 3️⃣ Ring 开发者注册（30 分钟，M0 最关键）

- 打开 https://developer.amazon.com/ring → 用 Amazon 账号注册开发者
- 目标：拿到 **sandbox / Ring test account** 的访问权限
- 注意记录（这些就是 Friction Log 素材）：注册耗时、是否要审核、有没有收费项、test account 是否提示需要 Ring 订阅
- **带回**：sandbox 能否产生事件 + 文档/API 形态截图或链接 → 我把真实适配器接进 `backend/app/ring_client.py`（webhook 接收端已按真实形态写好，只需配置）

## 4️⃣ AWS 账号 + Bedrock（20 分钟）

- https://aws.amazon.com 注册/登录 → 创建 IAM 用户（需 `bedrock:InvokeModel` 权限）→ 拿 AccessKey
- Console → Bedrock → Model access → 申请 **Nova Lite**（us-east-1）
- 顺便：https://amazonappdev2026.devpost.com 页面申请 **$150 AWS credits**（10/21 PT 截止）
- **带回**：把 AccessKey/Secret 配到本机（`aws configure` 或环境变量），别贴在对话里 → 我跑通真实 Nova 调用 + 补 Friction Log

## 5️⃣ 录制英文视频（10/16 前，脚本已备好）

- 打开 `docs/video-script.md`：7 段分镜、每段台词、拍摄清单都写好了
- `./scripts/dev.sh` 启动 → 看板上直接点「Try a test event」就是现成演示画面
- 录好传 YouTube（公开），**带回**链接 → 我填进全部提交材料
